# CartApp (MERN Stack)

This is a full-stack Cart application built using the MERN stack.

## Features
- User Signup & Login
- JWT Authentication
- Protected Routes
- Add / Remove Cart Items
- Persistent Cart using MongoDB
- Dark / Light Mode
- Responsive UI

## Tech Stack
Frontend:
- React (Vite)
- Tailwind CSS
- React Router
- Context API

Backend:
- Node.js
- Express.js
- MongoDB
- JWT

## How to Run

Backend:
1. cd server
2. npm install
3. npm run dev

Frontend:
1. cd client
2. npm install
3. npm run dev
